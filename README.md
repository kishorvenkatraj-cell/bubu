# Our Little Universe — 3 music tracks

## Add your music
Put your own MP3 files in the `assets` folder with these exact names:

- `opening-bgm.mp3` — starts after the correct nickname is entered and loops through the early pages.
- `dedicated-song.mp3` — starts when the dedicated-song page opens. The opening BGM stops first.
- `fingerprint-bgm.mp3` — starts when the fingerprint page opens after the dedicated song ends (or when she presses the continue button).

The MP3 files themselves are not included. Add your own audio.

## Preview
1. Extract the ZIP and open the folder in VS Code.
2. Add the three MP3 files to `assets/`.
3. Right-click `index.html` → Open with Live Server.
4. Save edits with Ctrl+S; hard-refresh Chrome with Ctrl+Shift+R.

## Edit your Tamil/Tamilish text
Edit the `SETTINGS` values at the top of `script.js` for the nickname, gift question, promise question, and promise message. Edit other visible page text in `index.html`.

## Browser audio note
Chrome may block autoplay until the visitor interacts with the page. The opening music begins after the nickname submit, and the dedicated song begins after the song-page button is pressed.

## Privacy note
GitHub Pages is public hosting. The nickname is a playful gate, not secure authentication. Gift choices are not sent to you or saved in a private dashboard.
